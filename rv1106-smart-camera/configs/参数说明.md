# RV1106 配置参数说明

`config.json` 是 `camera-daemon` 的运行配置。JSON 标准不支持注释，因此将每个重要字段的中文说明集中放在此文件；未提供的字段会使用 daemon 内置默认值。

| 字段 | 含义 |
| --- | --- |
| `socket_path` | Qt 与 daemon 通讯的 Unix Socket 路径。 |
| `log_path` | daemon 事件 JSONL 日志文件。 |
| `sensor_subdev` | SC3336 对应的 V4L2 sub-device，用于读取/写入传感器控制。 |
| `sender_path` | 项目媒体管线 `media-sender` 的可执行文件路径。 |
| `bridge_path` / `rtsp_url` | RTSP 预览桥接程序及其输入地址；仅桥接模式使用。 |
| `npu_path` | 本地 RKNN 人形检测程序路径。 |
| `iq_dir` | RKAIQ 使用的 IQ 调优文件目录。 |
| `isp_control_socket` | daemon 向媒体程序发送自动/手动 AE 指令的 Socket。 |
| `rkipc_path` / `rkipc_socket` | 系统 rkipc 进程及控制 Socket；项目退出时会恢复它。 |
| `backlight_control` / `backlight_path` | 是否允许本地 NPU 按人形存在状态控制背光，以及 sysfs 节点。 |
| `backlight_idle_seconds` | 未检测到人后关闭背光的空闲时间（秒）。 |
| `backlight_wake_hits` | 连续检测到人的次数达到该值后唤醒背光。 |
| `memory_watchdog_enabled` | 是否启用内存压力监控。 |
| `memory_available_min_kb` | 可用内存低于该值时计为一次低内存样本（KiB）。 |
| `memory_low_checks` / `memory_check_interval_ms` | 连续低内存样本数与检查周期；达到阈值后重启媒体链。 |
| `default_exposure` / `default_analogue_gain` | 手动曝光和模拟增益的初始值。 |
| `default_vblank` / `default_hflip` / `default_vflip` / `default_test_pattern` | V4L2 传感器控制的恢复默认值。 |
| `start_pipeline` / `start_npu` | 是否启动媒体管线和本地 NPU；实际启停行为以 daemon 实现为准。 |
| `auto_ae` | 初始是否由 RKAIQ 自动曝光/自动增益控制。 |
| `low_light_luma` | 上报亮度低于该值时记为暗帧。 |
| `low_light_frames` / `recover_frames` | 进入低照度状态和恢复正常状态所需连续帧数。 |
| `npu_latency_max_ms` | NPU 单帧推理延迟超过该值时记录高延迟事件。 |
| `restart_after_failures` / `restart_backoff_ms` | 媒体进程失败达到次数后的重启退避时间。 |
